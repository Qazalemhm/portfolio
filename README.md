# ⚡ <QM/> — Cybercore Developer Portfolio

A sleek, lightweight, and responsive personal portfolio website with a cyberpunk/futuristic visual aesthetic, built for showcasing projects, technical skills, and software development background.

## ✨ Features

- **Cyberpunk / Futuristic UI Design:** Custom CSS variables for neon glows, scanlines, polygon clips, and interactive hover states.
- **Clean & Modular Code:** Zero inline styles in HTML, adhering to BEM-inspired and dry CSS standards.
- **Smooth Navigation & Scroll:** Built-in smooth scrolling handler for quick access to the inline `#contact` section.
- **Fully Responsive Layout:** Optimized for all viewport sizes (Desktop, Tablet, Mobile) with a mobile hamburger navigation menu.
- **Zero Framework Overhead:** Pure HTML, CSS, and Vanilla JavaScript for maximum performance and fast load times.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic elements)
- **Styling:** CSS3 (Flexbox, CSS Grid, Custom CSS Variables, Keyframe Animations, Clip-paths)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Typography & Icons:** 
  - Google Fonts (*Orbitron*, *Fira Code*, *Inter*)
  - Font Awesome 6.4.0 (Icons)
